# ⚡ Knowhere Tech — Java Full Stack 2027 Learning Platform

> A complete, modern, lightweight, frontend-only interactive learning platform for mastering the Java Full Stack developer ecosystem in 2027.

---

## 🚀 Overview

**Knowhere Tech** is designed from the ground up to take developers from core fundamentals to job-ready engineering competence. The learning flow is centered around:

**Learn → See → Understand → Interact → Practice → Quiz → Track Progress**

Built with an **AMOLED Pure Dark theme**, crisp glassmorphism panels, interactive step-by-step visualizers, real-time code line explainers, and comprehensive technical interview prep.

---

## 🛠️ Tech Stack & Architecture

- **Core Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS + Custom AlgoVisual Design System (Pure AMOLED Black `#000000` + Emerald `#10b981`)
- **Animation**: Framer Motion
- **Icons**: Lucide React
- **Visualizers & Charts**: Custom Canvas / SVG Visualizers + Recharts
- **Storage & State**: React Context + IndexedDB (`idb`) + LocalStorage (100% Client-Side, Zero External Telemetry)
- **Deployment**: Netlify & Vercel SPA Ready (`_redirects`, `netlify.toml`, `vercel.json`)

9. **💼 8 Production Blueprints**: E-Commerce Microservices, Real-Time Chat, Multi-Tenant SaaS, API Gateway

## 🏃 Getting Started Locally

```bash
# Clone the repository
git clone https://github.com/MrGokulaKrishnan/Knowhere-Tech.git

# Navigate to project directory
cd Knowhere-Tech

# Install dependencies
npm install

# Start development server
npm run dev
```

The application will be running at `http://localhost:5173/`.

---

## 📦 Production Build

```bash
# Build production bundle
npm run build

# Preview build locally
npm run preview
```
